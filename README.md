# 天赋图鉴官网原型

这是一个无需安装即可预览的中、英、西三语静态网站原型。

## 预览

直接双击 `index.html`，或在此目录运行：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 已包含

- 中 / 英 / 西三语切换
- 跨文化天赋、外国人中文命名、东方战略三项服务
- 出生日期演示交互（仅浏览器本地计算）
- 九数主系统：1—9号人、完整计算过程、优势、平衡提醒和东方战略提示
- 可点击九数玄轮：确定性旋转并停在生日计算出的号码，支持重复转动和低动态模式
- FAQ 和基础 Schema.org 结构化数据，便于后续 GEO/SEO
- 手机和桌面响应式布局
- 三款与天赋故事匹配的中国风手珠 / 挂件商品原型
- 本地购物袋交互（当前不产生真实订单或付款）
- 外国人中文取名初选：原名首音、生日九数、农历年干五行、个人愿景三组候选名
- 每个候选名提供拼音、逐字含义、五行象征线索与《孙子兵法》行动解释

## 正式上线前需要补充

- 你的姓名、专业身份、照片与联系方式
- 服务流程、价格或预约方式
- 实际材质、尺寸、成本、库存、物流、支付与退换货政策
- 真实且经授权的匿名案例
- 独立的中英西 URL、完整文章库、隐私政策与服务免责声明
- 经研究和专家审校后的文化算法；当前生成器只是交互展示原型

## 算法边界

第二阶段以用户的“中西结合、助己助人”XMind 为方法母体，将线上流程重组为“先知己，再知彼”和“算—看—问—观”。涉及身体接触、疾病、创伤、财富或命运的内容不由网页自动推断。

当前报告以九数为主系统，并包含三个明确分开的层次：

- 九数主系统：将完整出生日期逐位相加并反复化简到1—9，对应1号创新领导型至9号丰富乐享型。
- 原创五维坐标：作为辅助雷达图，不是心理测评或传统命理。
- 中国历法视角：使用浏览器内置中国农历转换呈现农历年干支、年干五行与生肖；不是完整八字。
- 玛雅历法视角：使用 GMT 584283 相关常数呈现 Tzolk’in 的 13 数字与 20 日名组合；不作命运解释。
- 中文命名：以原名首音选择常见姓氏，以农历年干五行及五行相生方向选择用字，再结合九数与用户愿景形成三组初选；正式使用前仍需人工复核方言谐音、性别年龄语感、重名、职业场景及证件要求。
- 《孙子兵法》只作为行动与协作的文化解释框架，不用于断言命运或吉凶。

公开参考资料：香港天文台“天干和地支”及 Smithsonian National Museum of the American Indian “Living Maya Time”。
