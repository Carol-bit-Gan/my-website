# 天赋图鉴官网原型

这是一个无需安装即可预览的中、英、西三语静态网站原型。

## 预览

直接双击 `index.html`，或在此目录运行：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 已包含

- 中 / 英 / 西三语切换
- 跨文化天赋、外国人中文命名、东方战略三项服务
- 出生日期演示交互（仅浏览器本地计算）
- 原创文化坐标 v0.2：五维雷达图、核心与辅助原型、优势、平衡提醒和东方战略提示
- FAQ 和基础 Schema.org 结构化数据，便于后续 GEO/SEO
- 手机和桌面响应式布局
- 三款与天赋故事匹配的中国风手珠 / 挂件商品原型
- 本地购物袋交互（当前不产生真实订单或付款）

## 正式上线前需要补充

- 你的姓名、专业身份、照片与联系方式
- 服务流程、价格或预约方式
- 实际材质、尺寸、成本、库存、物流、支付与退换货政策
- 真实且经授权的匿名案例
- 独立的中英西 URL、完整文章库、隐私政策与服务免责声明
- 经研究和专家审校后的文化算法；当前生成器只是交互展示原型

## 算法边界

当前生日生成器使用可复核的原创文化坐标算法，同一生日会得到相同结果。它不属于八字、易经占卜、玛雅历法或心理测评；这些专业文化模块需要在文化顾问确认体系、资料来源和测试案例后单独接入。
